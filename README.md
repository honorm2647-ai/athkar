# أذكاري | أذكار الصباح والمساء

موقع عربي أنيق لأذكار الصباح والمساء بجميع الأذكار الصحيحة ومصادرها.

## المزايا
- 🌅 / 🌙 تبويب الصباح والمساء مع صياغة دقيقة (أصبحنا / أمسينا)
- 📚 كل ذكر موثق بالمصدر ورقم الحديث ودرجته
- 📿 مسبحة إلكترونية لكل ذكر متعدد مع حلقة تقدم
- 🔍 بحث فوري + شريط تقدم + حفظ التقدم يومياً
- 🌓 ثيم ليلي / نهاري + تكبير وتصغير الخط (70% - 160%)
- ✒️ خط ثمانية الرسمي عبر CDN

## التشغيل محلياً
افتح `index.html` مباشرة، أو:
```powershell
npx serve .
```

## النشر على GitHub Pages
الموقع Static بالكامل (HTML/CSS/JS) وجاهز للنشر من فرع `main` ومجلد `Root`.
